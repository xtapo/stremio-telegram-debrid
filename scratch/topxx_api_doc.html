API public, không cần token để gọi API hoặc phát embed. Nếu đã có tài khoản API, nên gửi kèm để hệ thống tự gắn mã tài khoản vào embed link, giúp kỹ thuật nhận diện sớm và hỗ trợ nhanh hơn khi cần.

Header Required Description
X-API-Key Optional API key của tài khoản tích hợp nếu đã được cấp.
X-API-Secret Optional API secret tương ứng. Chưa có header vẫn gọi API bình thường.

Chỉ dùng X-API-Key / X-API-Secret ở server/plugin khi gọi API (khuyến khích gửi).
